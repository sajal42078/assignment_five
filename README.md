### 1️⃣ What is the difference between var, let, and const?

answer : Var is function scoped, can be re-declared and re-assigned .
Let is block scoped, can be re-assigned, but cannot be 
re-declared in the same scope.
Const is also block scoped, cannot be re-declared or re-assigned after declaration.

### 2️⃣ What is the spread operator (...)?

answer : The spread operator (...) in JavaScript is used to expand elements of an array, or object.It is commonly used to copy 
arrays or objects, merge them or pass multiple values into a function.

### 3️⃣ What is the difference between map(), filter(), and forEach()?

answer : map(), filter(), and forEach(), are JavaScript array methods, but they have different purposes.
map() transforms data, filter() selects data and forEach() is used for iteration only.

### 4️⃣ What is an arrow function?

answer :  An arrow function is a shorter way to write functions in JavaScript using the => syntax.
Example , 
          const add = (a,b) => a + b ;
is an array function that returns the sum of two numbers.

### 5️⃣ What are template literals?

answer : Template iterals are a modern JavaScript way to create strings using backticks(` `) instead of quotes.They allow you to 
insert variables using ${} and support multiline strings.
